# ☕ Behavioral CRM & Customer Intelligence

Projeto inspirado no modelo orientado a dados da Luckin Coffee, focado em análise comportamental de clientes, segmentação inteligente e campanhas automatizadas.

A proposta é transformar dados transacionais de uma cafeteria em inteligência de negócio utilizando Python, Machine Learning e análise temporal.

---

# 🚀 O que o projeto faz

* analisa comportamento de compra dos clientes
* identifica padrões de recorrência
* segmenta clientes automaticamente com KMeans
* detecta possíveis clientes em risco de churn
* sugere campanhas e ações personalizadas
* explora previsão de próxima compra

---

# 📊 Dados Utilizados

O dataset contém informações como:

* usuário
* valor gasto
* produto comprado
* horário da compra
* dia da semana
* forma de pagamento

---

# 🧠 Features Criadas

* total_gasto

---

# 🤖 Segmentação de Clientes

O projeto utiliza KMeans para identificar perfis comportamentais como:

* clientes fiéis
* clientes em risco de churn
* consumidores de fim de semana
* compradores noturnos
* clientes de rotina matinal

---

# 🌊 Fourier & Comportamento Temporal

Uma das ideias exploradas no projeto é utilizar Fourier Transform para detectar periodicidade e padrões recorrentes de consumo, permitindo evoluir para previsões de próxima compra e campanhas mais inteligentes.
